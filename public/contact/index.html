Contact

Taglet is run by one person, so the best way to reach it is a plain email. Expect a reply within a few days.

Email

hello@taglet.net

What to write about

  • Something broke. Tell me what you did, what you expected, your device and browser, and the file type if it was about a specific song. Please don’t attach music you don’t have the right to share.
  • An idea or a missing format. Features have come straight from messages like these.
  • Account or privacy requests. Signed-in users can delete their account and everything stored with it from the account sheet in the app. If you can’t, email me from the address on the account.
  • Shared-link reports. If a shared album link contains something that shouldn’t be there, send the link. Shared links expire after 30 days in any case.

Code and issues

Taglet is open source. You can also file an issue on GitHub.
